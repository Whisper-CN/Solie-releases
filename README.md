# Solie

Solie 是本地多模态创作工作台，提供自由画布、电商套图、视频广告、在线生图、在线对话及图片处理工具。

此仓库仅用于发布安装包、版本说明和更新信息，不包含产品源码。

## 下载

请前往本仓库的 [Releases](https://github.com/Whisper-CN/Solie-releases/releases) 下载：

- macOS Apple Silicon：`Solie-版本号-mac-arm64.dmg`
- Windows x64：`Solie-版本号-win-x64-Setup.exe`

当前安装包未签名。首次使用请在应用设置中配置自己的 API Key。

## 更新

从 0.1.1 起，可在「设置 → 关于 → 检查更新」查看新版本并打开安装包下载链接。下载后等待生成任务结束、保存项目并退出 Solie，再安装新版。当前不自动安装或重启。

Mac 数据位于 `~/Library/Application Support/Solie/`，Windows 数据位于 `%APPDATA%\Solie\`。正常覆盖安装保留项目和设置，请勿删除数据目录。
